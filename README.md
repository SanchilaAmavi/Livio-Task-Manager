# 🌟 Livio – Task & Productivity Manager

**Livio** is a modern, professional, and fully interactive **task and productivity management application** built using **Python and Streamlit**. It helps users efficiently organize, track, and visualize their tasks — all in one clean and intuitive dashboard.

---

## Features

- **Add, Update, Delete Tasks** – Easily manage your daily tasks.  
- **Task Cards** – Beautiful cards showing task details, priority, deadline, and status.  
- **Progress Bars** – Visualize task completion at a glance.  
- **Priority & Status Color Coding** – Quickly identify high-priority and overdue tasks.  
- **Calendar / Timeline View** – See tasks by date for better planning.  
- **KPIs & Interactive Charts** – Track total tasks, completed, pending, and overdue tasks.  
- **Search & Sort** – Find tasks quickly and organize by priority or deadline.  
- **Overdue Task Highlights** – Stay on top of deadlines.  

---

## Tech Stack

- **Python 3.11**  
- **Streamlit** – For web-based interactive dashboard  
- **Pandas** – For task data management  
- **CSV** – Task storage (simple, reliable, and easy to edit)
